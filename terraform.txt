Second Lecture:-Terraform Workflow:-

1. Init Used to initialize a working directory containing terraform config files This is the first command that should be run after writing a new terraform config.Downloads Providers

2. ValidateValidates the terraform config files in that respective directory to ensure they are Syntactically valid and internally consistent.

3. PlanCreates an execution planTerraform performs a refresh and determines what actions are necessary to achieve the desired state specified in the config files.

4. ApplyUsed to apply the changes required to reach the desired state of the configuration.By default, apply scans the current directory for the config and applies the changes appropriately.

5. DestroyUsed to destroy the managed infrastructureThis will ask for confirmation before destroying.
